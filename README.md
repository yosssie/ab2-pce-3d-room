# ab2-pce-3d-room

PCエンジン版『アフターバーナーII』の SERVICE MODE 内「3D ROOM」を、Web ブラウザで動く形に再現したものです。

原作のプログラムを解析して判明した仕様（立体の座標、色の対応、回転・ズーム・遷移の挙動）をもとに、描画は自前で実装しています。原作の画像データは使っていません。

## 遊び方

`index.html` をブラウザで開くだけで動きます（単一ファイル・外部読み込みなし）。スマホでも操作できます。

## 操作

- ↑：PATTERN（立体の切り替え）
- ↓：COLOR（色の切り替え）
- RUN(Enter)：COORD（SPEED を調整する軸の切り替え）
- ←→：SPEED（選択されている COORD が対象）
- SEL(Shift)：STOP（選択されている COORD が対象）
- I(Z) / II(X)：ZOOM
- ドラッグ：回転（勢いをつけて離すと、しばらく回り続けます）
- ホイール / ピンチ：ZOOM
- 画面下のボタンからも操作できます

## 内容

- 立体は全24種（基本の8種×49ボール、64ボール版、144ボール版）
- パターン切り替えはモーフィング遷移（ボールが形を変えながら移る）
- 「なめらか」オフで原作準拠の挙動（角度・座標の整数量子化）、オンで滑らかな回転。位置のパースは両モードとも原作実測の弱い透視投影
- 奥行き表現3種、背景3種
- 座標編集モード付き（ボールの位置をドラッグ／数値入力で編集、Undo/Redo、グリッドスナップ）

## 補足

- 非公式のファンメイド再現です。原作の権利者とは関係ありません。
- 座標データは原作の解析に基づきます。ボールの絵と色は自前で生成しています。
